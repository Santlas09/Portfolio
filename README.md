# Santiago Reyes Herrera — Personal Portfolio

Personal portfolio website built to showcase my profile, technical skills, university projects, achievements, and contact information.

## Overview

This portfolio presents my background as a Systems Engineering student and developer focused on web, mobile, and software solutions. It includes featured university projects, technical skills, professional information, and a downloadable CV.

## Features

* Responsive design for desktop, tablet, and mobile
* Hero section with profile image and CV download
* About Me section
* Technical skills section
* Featured university projects
* Achievements section
* Contact section with email, GitHub, and LinkedIn
* Smooth scrolling navigation
* Basic SEO metadata
* Framer Motion animations

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* Framer Motion
* React Icons

## How to Run Locally

```bash
git clone https://github.com/Santlas09/portfolio.git
cd portfolio
npm install
npm run dev
```

Open the project in your browser:

```txt
http://localhost:3000
```

## Build for Production

```bash
npm run build
```
